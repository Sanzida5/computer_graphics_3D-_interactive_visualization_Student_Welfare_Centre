# SWC 3D Interactive Visualization

A real-time 3D Student Welfare Centre visualization project developed using OpenGL and C++.

## Features
- Dynamic lighting (Directional, Point, Spot)
- Phong and Gouraud shading
- Animated pedestrians
- Animated ceiling fans and doors
- Water ripple animation
- Procedural textures
- Bezier Swept Surface
- Catmull-Rom Spline
- Ruled Surface

## Technologies Used
- C++
- OpenGL 3.3
- GLSL
- GLFW
- GLAD
- GLM
